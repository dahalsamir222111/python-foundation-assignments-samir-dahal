## Common Challenges & Solutions

### Challenge 1: Modulo operator
**Problem:** Understanding `%` for checkpoints.
**Solution:** `number % 3 == 0` means perfectly divisible by 3.

### Challenge 2: While loop logic
**Problem:** Understanding when loop stops.
**Solution:** Loop continues while condition is True. Break exits immediately.

### Challenge 3: isinstance() with None
**Problem:** None is not an integer.
**Solution:** isinstance(value, int) only returns True for integers.

### Challenge 4: Nested dictionary access
**Problem:** Getting values from nested dictionaries.
**Solution:** Use `dict[key1][key2]` to access nested values.
